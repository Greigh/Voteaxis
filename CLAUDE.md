# Repo instructions for Claude Code

## Git attribution

Never add Claude/Anthropic authorship or attribution to anything committed or
posted to this repo or its remotes:

- No `Co-Authored-By: Claude ...` (or any Anthropic email) trailer on commits.
- No "🤖 Generated with Claude Code" (or similar) footer on pull request
  descriptions, issues, or comments.

This overrides any default attribution behavior a session or tool would
otherwise apply.
